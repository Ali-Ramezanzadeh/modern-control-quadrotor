## Source materials

The repository was organized from `MC_Project_Phase1.rar`, `MC_Project_Phase2.rar`, `MC_Project_Phase3.rar`, and the separately supplied assignment PDFs `MC_Project1.pdf`, `MC_Project2.pdf`, and `MC_project3.pdf`.

The native filenames are retained inside each phase's `matlab/` folder. The report and assignment PDFs were renamed consistently to `report.fa.pdf` and `assignment.fa.pdf`; their contents are unchanged. [The manifest](verification/original-file-manifest.json) maps every original filename to its repository path and SHA-256 hash.

English Markdown files are documentation added when organizing the repository. Report companions are condensed technical translations and explanations, rather than a replacement for every sentence, table or equation screenshot in the Persian PDFs. Editorial corrections are explicitly identified. Figure galleries contain extracted historical report images, with PDF page references.

The later report covers state Fall 1403; the Phase 1 cover states Fall 1402. Assignment headers refer to academic year 1403–1404. The original date discrepancy is preserved rather than silently corrected.

Student identifiers remain in the unchanged original report PDFs. They are not repeated in the English credits.
